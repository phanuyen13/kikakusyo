1. エグゼクティブ・サマリー (Executive Summary)

【事業コンセプト】日本のSME（中小企業・店舗）向け AIブランドアンバサダー自動運用プラットフォーム

本事業は、日本の飲食店・美容サロン・D2Cブランドなどの中小企業（SME）を対象に、一貫性のあるAIインフルエンサー（顔出しNG対応）の生成から、日本語敬語キャプション作成、SNS（Instagram, TikTok, X, LINE）への自動投稿までをワンストップで提供するB2B SaaSです。 従来、月額30万円以上かかっていたSNS運用外注費を月額2.98万円〜に削減し、深刻な人手不足と「顔出し」に関する課題を解決します。

2. 市場背景とSMEの3大課題 (Market Background & Pain Points)

❶人手不足と運用負荷

店舗オーナーやスタッフが本業に追われ、SNS運用の継続が困難。コンテンツ企画や毎日更新にかかるリソースが極めて不足している。

❷「顔出しNG」の文化障壁

プライバシー意識が高い日本では、スタッフが個人の顔をSNSに出すことへの抵抗感が強い。結果として人間味のあるコンテンツが作れない。

❸運用代行の高額なコスト

外部のSNSマーケティング代理店に頼むと月額30万〜50万円の費用が発生し、小規模店舗やSMEの予算感と大きく乖離している。

3. 製品概要とシステムフロー (Product Overview & Architecture)

ユーザー（店舗オーナー）は簡単なWebダッシュボードから商品写真やキャンペーン概要を入力するだけで、AIが専属のインフルエンサーとして投稿を作成・自動配信します。

4. 競合優位性と技術的コア (Key Differentiators & Tech Core)

機能・技術モジュール 技術仕様 & 特徴 SME顧客への提供価値
Face Consistency Pipeline Flux / SDXL + LoRA 専属学習により、人物の顔・体型・雰囲気の統一感を100%保持。 ブランドの「顔」となる専属AIモデルを低価格で所有可能。
Japanese Localized LLM Agent 日本のビジネス文脈（敬語、絵文字、顔文字 (^^)、SEOハッシュタグ）に特化したプロンプトエンジニアリング。 自然で親しみやすい日本語文章の自動作成（修正不要レベル）。
Compliance Guardrails 薬機法・景表法（ステルスマーケティング規制）の自動リスク検知フィルターを統合。 炎上リスクや法令違反を未然に防止し、安心して運用可能。
Multi-Channel Orchestrator Meta Graph API, TikTok API, X API v2を統合したAPI投稿エンジン。 1回の作成で複数SNSへ最適化フォーマットで一括投稿。
